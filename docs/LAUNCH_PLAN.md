# Launch plan

Release scope: account-free, read-only physical product discovery. The agent sends explicit interests and filters each time. No OAuth, database, saved profile, automatic alerts, purchases or affiliate rewriting.

## Completed locally
- Official MCP SDK Cloudflare Worker, anonymous deal_scan tool and strict input validation.
- Source caching, bounded fetching, safe original links, market/currency/price/age filters and clear unavailable-source responses.
- Aggregate anonymous rate limit, host/origin validation and request-size bounds.
- Agent-first landing, truthful install availability, legal/support pages, icon/skill, release ZIP builder, review scenarios and CI.
- Clean npm install, zero known dependency advisories, TypeScript and Worker build pass; portable manifests validate against published schemas.
- 16 tests: independent SDK protocol/search, no authentication, no retained preferences, validation, source failures, filters, host/origin, rate limit and domain challenge.

## Remaining external launch gates
1. A source whose terms permit this product's reuse, filtering and attribution. Public RSS alone does not settle that question. Feed use remains disabled.
2. Cloudflare login and a real PUBLIC_ORIGIN; deployed runtime and anonymous MCP checks.
3. Publisher/legal identity and private support contact.
4. Real ChatGPT developer-mode tests, walkthrough recording, identity/domain verification and directory review followed by publication.
5. Actual Muse requirements and integration verification before claiming Muse support.

Affiliate monetization is deferred pending merchant/network approval and confirmation of platform policy. Review approval and public launch are not complete.
